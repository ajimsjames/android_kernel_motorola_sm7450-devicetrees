# Motorola SM7450 Kernel Device Trees

Device tree sources (DTS/DTSI) for Motorola SM7450 (Snapdragon 7s Gen 2) platform devices.

## Features

* Target platform: Qualcomm SM7450 (`waipio` / `tank`)
* Pin control, clocks, display, camera, audio, and peripheral device nodes for Motorola SM7450 devices.
